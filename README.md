# DenaProbe — پروژه بازنشسته‌شده

این پروژه متوقف شده و دیگر در زیرساخت NVL استفاده نمی‌شود.

از این مخزن برای ساخت، فلش یا استقرار Firmware، Collector، پروتکل‌های DPT/1 و DPT/2 یا سرویس‌های Core استفاده نکنید.

کدها، قراردادها، مستندات، آزمون‌ها و گردش‌کارهای اجرایی از شاخه اصلی خارج شده‌اند. تاریخچه Git برای حفظ سوابق فنی و امکان بازیابی در صورت نیاز باقی می‌ماند.

## وضعیت بازنشستگی

- Firmware و ابزارهای ESP32: بازنشسته
- DPT/1 و DPT/2: بازنشسته
- Collector و اتصال Core: بازنشسته
- گردش‌کارهای CI و اسکریپت‌های استقرار: حذف‌شده
- داده‌های تاریخی و کلیدهای دستگاه روی سرور: خارج از این مخزن و بدون تغییر

برای جلوگیری از ارسال داده پس از بازنشستگی، دستگاه فیزیکی ESP32 باید خاموش شود. حذف این مخزن به‌تنهایی Firmware نصب‌شده روی برد را پاک نمی‌کند.
